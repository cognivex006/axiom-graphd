# Managed project instructions

Axiom can add a small managed instruction block that points a coding agent
to `.axiom/agent/POLICY.md`. The ownership manifest records the content Axiom
last wrote so later updates can preserve human edits.

Review [project setup](guides/bootstrap.md) before applying a plan.
Existing repository instructions and host permissions remain in force.
A missing ownership record or edited managed block needs review; do not
replace an entire `AGENTS.md` or another host's instruction file to resolve it.
